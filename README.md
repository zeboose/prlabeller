# PR Labeller

A native label editor for the Mac. It opens the `.label` files you already have
and prints to a LabelWriter through the driver you already have. No Rosetta.

### → [Download and full details](https://zeboose.github.io/prlabeller/)

Free and fully unlocked until 1 March 2027. macOS 14 or later, Apple Silicon
and Intel. Signed and notarised by Apple.

---

## Why this repository has no code in it

This is where the downloads and the download page live. The application's source
is not public, and this repository holds none of it — so if you arrived looking
for code, there is none here to find.

- **[Releases](../../releases)** — the disk image, and the notes for each version
- **[Help](https://zeboose.github.io/prlabeller/help.html)** — the same help page
  that ships inside the app

Issues are switched off deliberately. Problem reports come by email, through
**Settings ▸ Diagnostics ▸ Send…** in the app, which attaches the technical
detail that makes a report worth acting on. An issue tracker nobody is watching
looks like a way to be heard and is not.

Anything at all: **prlabeller@gmail.com**

## What this is not

PR Labeller is an independent program. It is **not made by, endorsed by, or
connected to Sanford, L.P. or its subsidiaries**. DYMO is their trademark, used
here only to say plainly which files this program reads and which printers it
prints to.

It contains none of their software — no templates, no stock catalogue, no driver
files. Every label size it offers is read from the driver already installed on
your own Mac, every time it runs.

**On label rolls:** some newer LabelWriter models accept only rolls the printer
itself recognises. That is decided inside the printer's own firmware, before
this program is involved at all. PR Labeller does nothing about it and never
will — not as an option, not as a plug-in, not on request.
